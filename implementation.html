Stage 1 · Sense

Perception: from pixels to a floor position

The camera gives us a 2D bounding box. To drive to the object we need its 3D position in the map. The C922 has no depth sensor, so we assume the object rests on the floor plane.

1 · Detection

We take the bottom-center of the bounding box as the pixel where the object touches the floor. Which detector and why

2 · Camera model

The pinhole model maps a 3D point to a pixel through the intrinsics $K$ (from calibration) and the camera pose $[R\,|\,t]$:

$$\lambda\begin{bmatrix}u\\v\\1\end{bmatrix} = K\begin{bmatrix}R & t\end{bmatrix}\begin{bmatrix}X\\Y\\Z\\1\end{bmatrix},\qquad K = \begin{bmatrix}f_x & 0 & c_x\\ 0 & f_y & c_y\\ 0&0&1\end{bmatrix}$$

Calibrated $K$: paste values from camera_calibration

3 · Back-project and intersect the floor

Inverting the projection gives a ray, not a point. We rotate it into the robot frame with the camera's mounted pose $g_{bc} = (R_{bc}, \mathbf{o}_b)$ and intersect it with the floor $z = 0$:

$$\mathbf{d}_c = K^{-1}\begin{bmatrix}u\\v\\1\end{bmatrix},\qquad \mathbf{d}_b = R_{bc}\,\mathbf{d}_c,\qquad \mathbf{p}(s) = \mathbf{o}_b + s\,\mathbf{d}_b$$ $$p_z(s^\ast) = 0 \;\Rightarrow\; s^\ast = -\frac{o_z}{d_z}\quad(d_z < 0),\qquad \mathbf{p}_{\text{map}} = g_{\text{map},b}\;\mathbf{p}(s^\ast)$$

The last step uses the TF chain camera_link → base_link → odom → map, which AMCL keeps up to date.

Error grows with distance squared. For a camera at height $h$ seeing a point at range $r$, a pixel error $\Delta v$ becomes a range error of about $\Delta r \approx \dfrac{h^2 + r^2}{h}\cdot\dfrac{\Delta v}{f_y}$. That's why we re-detect up close before grasping. Try it below: click near the horizon and watch the "1 px error" readout.

def image_callback(self, msg):
    frame = self.bridge.imgmsg_to_cv2(msg, "bgr8")
    box = self.detector(frame)                    # our detector
    if box is None:
        return
    u, v = box.bottom_center()                    # floor contact pixel
    d_cam = self.K_inv @ np.array([u, v, 1.0])    # ray in camera frame

    tf = self.tf_buffer.lookup_transform("base_link", msg.header.frame_id, Time())
    o, R = to_origin_and_rotation(tf)
    d = R @ d_cam
    if d[2] >= 0:                                 # ray points above the horizon
        return
    p_base = o + (-o[2] / d[2]) * d               # intersect z = 0
    self.publish_target(p_base, frame_id="base_link")
Stage 2 · Plan

Navigation: getting within arm's reach

We map the lab once with slam_toolbox / Cartographer, then localize with AMCL and plan with Nav2. Our job is choosing where to stop.

Approach pose

Stop at a standoff distance $d^\ast$ from the object, along the line from the robot to it, facing the object:

$$\hat{\mathbf{u}} = \frac{\mathbf{p}_o - \mathbf{p}_r}{\lVert \mathbf{p}_o - \mathbf{p}_r\rVert},\qquad \mathbf{p}_g = \mathbf{p}_o - d^\ast\,\hat{\mathbf{u}},\qquad \psi_g = \operatorname{atan2}(\hat u_y, \hat u_x)$$

Nav2 takes orientation as a quaternion: $q = \big(0,\,0,\,\sin\tfrac{\psi_g}{2},\,\cos\tfrac{\psi_g}{2}\big)$. The best $d^\ast$ puts the object in the middle of the arm's reachable floor band (see the reach map).

Stage 3 · Act

Manipulation: kinematics of the SO-101

MoveIt 2 does the full 5-DOF inverse kinematics and collision checking from our URDF. The math below is the model it works from, plus a planar version that shows how floor grasps work.

Forward kinematics (product of exponentials)

With joint twists $\xi_i$ expressed in the base frame at the zero configuration:

$$g_{st}(\theta) = e^{\hat{\xi}_1\theta_1}\,e^{\hat{\xi}_2\theta_2}\,e^{\hat{\xi}_3\theta_3}\,e^{\hat{\xi}_4\theta_4}\,e^{\hat{\xi}_5\theta_5}\;g_{st}(0),\qquad \xi_i = \begin{bmatrix}-\omega_i\times q_i\\ \omega_i\end{bmatrix}$$
Joint$\omega_i$$q_i$
1 shoulder pan$(0,0,1)$from URDF
2 shoulder liftaxispoint
3 elbow flexaxispoint
4 wrist flexaxispoint
5 wrist rollaxispoint

Inverse kinematics for a top-down floor grasp

Pan to face the object, $\theta_0 = \operatorname{atan2}(y, x)$. Pointing the gripper straight down fixes the wrist $L_3$ above the object, which leaves a 2-link problem in the arm's plane for the wrist point $(r, z)$:

$$\cos\theta_2 = \frac{r^2 + z^2 - L_1^2 - L_2^2}{2L_1L_2},\qquad \theta_1 = \operatorname{atan2}(z, r) - \operatorname{atan2}\!\big(L_2\sin\theta_2,\; L_1 + L_2\cos\theta_2\big)$$ $$\theta_3 = -\tfrac{\pi}{2} - \theta_1 - \theta_2 \quad\text{(keeps the gripper vertical)}$$

A solution exists only when $|L_1 - L_2| \le \sqrt{r^2+z^2} \le L_1 + L_2$. Of the two solutions ($\pm\theta_2$) we use elbow-up, which keeps the forearm clear of the floor.

Reach map: where Nav2 needs to stop

Sweeping the IK solution around the pan joint gives the robot's reachable floor region: a ring from $r_{\min}$ to $r_{\max} = \sqrt{(L_1 + L_2)^2 - (L_3 - z_s)^2}$ around the shoulder. Nav2 only gets the robot within its goal tolerance, so the whole tolerance disc has to fit inside that ring.

Grasp sequence

  1. Pre-grasp: 8 cm above the object, gripper open, vertical.
  2. Descend: straight down (Cartesian path) to grasp height.
  3. Close: gripper to target effort, not position, so it doesn't crush.
  4. Lift and stow close to the body for driving.

def move_to(pose):
    arm.set_start_state_to_current_state()
    arm.set_goal_state(pose_stamped_msg=pose, pose_link="gripper_link")

    if not plan:

    robot.execute(plan.trajectory, controllers=[])
